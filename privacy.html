개인정보 처리방침 (ssabom-uploader)

시행일: 2026년 10월 16일

누가 쓰는 도구인가

ssabom-uploader는 YouTube 채널 "AI 머니랩"(@Nmoneylab)의 운영자 본인만 쓰는 개인용 도구입니다. 운영자 외의 사용자는 이 도구에 로그인하지 않으며, 다른 사람의 개인정보를 받지 않습니다.

접근하는 정보와 사용 목적

운영자가 Google 로그인으로 허용한 범위(YouTube 영상 업로드와 관리) 안에서, 운영자 본인 채널의 영상 정보(제목, 설명, 공개 상태)를 읽고 영상과 썸네일을 올립니다. 그 외 목적으로는 쓰지 않습니다.

저장과 공유

로그인 토큰은 운영자 본인의 컴퓨터에만 암호화해 저장하며, 외부 서버로 보내거나 제3자에게 제공하지 않습니다. 이 도구는 별도의 서버나 데이터베이스에 개인정보를 수집하지 않습니다. 광고, 판매, 분석 목적의 공유도 하지 않습니다.

삭제

운영자는 Google 계정의 연결된 앱 관리에서 언제든 접근 권한을 취소할 수 있고, 저장된 토큰 파일을 지울 수 있습니다.

YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 사용함으로써 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. 이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

문의
